## Projeto Prático — Sistema Sinta Música

O **Sistema Sinta Música** é um projeto desenvolvido em Python para aplicar, na prática, os conhecimentos adquiridos nos quatro primeiros módulos do curso.

O projeto simula um sistema simples de gerenciamento de alunos de uma escola de música, permitindo praticar lógica de programação e os principais fundamentos da linguagem Python.

### Funcionalidades

* Cadastro de alunos
* Listagem de alunos cadastrados
* Busca de alunos por nome
* Exibição das informações do sistema
* Menu interativo
* Encerramento do programa

### Conceitos praticados

* Variáveis e tipos de dados
* `input()` e `print()`
* Operadores de comparação e associação
* Estruturas condicionais
* Estruturas de repetição `for` e `while`
* Listas
* Método `.append()`
* Métodos de strings, como `.strip()` e `.lower()`
* F-strings
* Variáveis booleanas para controle de fluxo
* Organização e indentação do código
* Comentários voltados à explicação da lógica

### Objetivo do projeto

O objetivo principal foi transformar os conhecimentos estudados nos módulos 1 a 4 em uma aplicação prática, permitindo consolidar a lógica de programação e desenvolver a capacidade de resolver problemas utilizando Python.

Este projeto representa o **primeiro marco prático da minha formação em Python** e será utilizado como base para acompanhar minha evolução ao longo dos próximos módulos.
