# Resumo — Módulo 4: Manipulando Strings

## Objetivo do módulo

Aprender a manipular textos utilizando os principais recursos da classe `str`.

---

# Aula 1 — Métodos de String

Aprendi:

- upper()
- lower()
- title()
- strip()
- lstrip()
- rstrip()
- join()

Conceito importante:

Strings são imutáveis.

---

# Aula 2 — Interpolação

Aprendi:

- f-string
- format()
- operador %

Conceitos importantes:

- A interpolação cria uma nova string.
- Posso utilizar expressões dentro das chaves das f-strings.

---

# Aula 3 — Fatiamento (Slice)

Aprendi:

- Índices positivos.
- Índices negativos.
- Slice.
- Step.
- Inverter strings.

Conceito mais importante:

O índice inicial entra.
O índice final não entra.

---

# Aula 4 — Strings de múltiplas linhas

Aprendi:

- Triple quotes.
- Menus.
- Documentação.
- Relatórios.
- Integração com f-string.

---

# Conhecimentos adquiridos

Ao concluir este módulo consigo:

- Manipular textos.
- Alterar maiúsculas e minúsculas.
- Remover espaços.
- Interpolar variáveis.
- Selecionar partes de uma string.
- Percorrer textos por índices.
- Inverter strings.
- Criar mensagens e menus organizados.

---

# Conclusão

Este módulo forneceu a base para manipulação de textos em Python, um conhecimento utilizado diariamente no desenvolvimento de aplicações.
