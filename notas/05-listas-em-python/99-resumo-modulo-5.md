# Resumo — Módulo 5: Listas em Python

## Objetivo do módulo

Aprender a criar, acessar, alterar e manipular listas utilizando os principais recursos da classe `list`.

---

# Aula 1 — Listas

Aprendi:

* Criação de listas.
* Listas vazias.
* Índices positivos.
* Índices negativos.
* Alteração de elementos.
* `len()`.
* Slicing.
* Percorrer listas com `for`.
* Listas com diferentes tipos de dados.

Conceitos importantes:

* Listas são mutáveis.
* Os índices começam em `0`.
* O índice inicial do slicing entra. O índice final não entra.

---

# Aula 2 — Métodos da classe `list`

Aprendi:

### Adicionar elementos

* `append()`
* `insert()`
* `extend()`

### Remover elementos

* `remove()`
* `pop()`
* `clear()`

### Consultar elementos

* `index()`
* `count()`

### Organizar elementos

* `sort()`
* `reverse()`

Conceitos importantes:

* `append()` adiciona um elemento ao final.
* `insert()` adiciona em uma posição específica.
* `extend()` adiciona elementos de outra sequência.
* `remove()` remove pelo valor.
* `pop()` remove pelo índice e retorna o elemento removido.
* `sort()` ordena os elementos.
* `reverse()` apenas inverte a ordem atual.
